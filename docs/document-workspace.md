# Панель документов Isaac

Проверено локально 2026-10-05, сайт: http://127.0.0.1:5176.

## Возможности

- Нажатие на вложение в сообщении открывает правую панель. Несколько документов можно держать во вкладках, менять масштаб и разворачивать панель.
- DOCX: исходная страничная разметка через docx-preview, включая таблицы, колонтитулы и изображения. Для правок используется отдельная структурированная текстовая редакция.
- PDF: исходные страницы отображаются через PDF.js, есть перелистывание. Редактируется извлечённая текстовая версия, не оригинальные PDF-объекты.
- XLSX/XLS/CSV: таблица с адресами ячеек, листами книги, объединениями и основными стилями. Можно редактировать значения и формулы. Формулы в предпросмотре не пересчитываются: XLSX помечается для полного пересчёта при открытии в Excel.
- Текст/Markdown: структурированное представление и редактор.
- Изображения: просмотр с масштабированием и скачивание оригинала, без графического редактора.
- Экспорт текстовой редакции в настоящий DOCX/PDF; таблицы — в XLSX/CSV. Исходник скачивается отдельно и не изменяется.

## Хранение и безопасность

Оригинальные файлы сохраняются как file-parts в PostgreSQL движка вместе с сообщением. В модель передаётся извлечённый текст Office/PDF, а не их бинарные данные. Изображения идут существующим путём OCR в gateway.

Суммарный размер вложений сообщения/сценария ограничен 20 МБ. На engine установлен предел тела запроса 30 МБ с учётом base64; для правок — 2 МБ.

Правки сохраняются только кнопкой «Сохранить» в `document_revisions`. Ключ включает пользователя, диалог и документ; API проверяет принадлежность диалога. Каждое сохранение увеличивает revision; устаревшее сохранение из другой вкладки получает 409, не перезаписывая последнюю редакцию. Таблица создаётся идемпотентно в `initSchema()` при запуске engine, отдельного ручного SQL для текущей схемы не требуется.

HTML очищается перед просмотром, сохранением и экспортом. Удаляются скрипты, обработчики событий, внешние изображения и опасные ссылки. Markdown документов обрабатывает отдельный экземпляр Marked, независимый от асинхронных расширений чата. Стилям исходных DOCX присваивается уникальное пространство имён, чтобы открытые документы не меняли разметку друг друга. При смене аккаунта открытые документы очищаются.

Несохранённые правки защищены предупреждениями при закрытии панели, уходе со страницы и обновлении. Ошибки одного файла не обрушивают чат.

## Ручная приёмка

В отдельный локальный тестовый диалог через интерфейс загружены contract.docx, contract-en.pdf и balance.xlsx. Модель ответила по всем трём файлам. Проверено:

- вложения сохранились после обновления страницы;
- исходный DOCX показал заголовки и таблицу услуг;
- PDF показал две страницы, перелистывание работает;
- изменение ячейки B2 сохранилось на сервере и загрузилось после обновления;
- правка текста DOCX сохранилась и загрузилась после обновления;
- закрытие без сохранения восстановило предыдущую редакцию;
- переключение вкладок и разворачивание панели;
- предпросмотр готового договора из юридического сценария через кнопку «Предпросмотр»;
- подготовка DOCX/PDF/XLSX через интерфейс без новых ошибок в консоли.

Встроенный браузер не вернул событие скачивания для blob-ссылок, поэтому наличие файла в папке пользователя вручную не подтверждено. Содержимое экспортов отдельно проверено автоматическими тестами: фактический DOCX ZIP/XML, читаемый кириллический PDF, изображения без изменения пропорций, объединённые PDF-ячейки, XLSX с сохранёнными стилями/формулами/объединениями/другими листами и дополнительными ZIP-частями.

Проверки типов прошли для app, UI, engine, billing и doc-tools. Полные тестовые наборы: app 359/359, UI 21/21, engine 14/14 (включая настоящий PostgreSQL и API проверки доступа/ревизий), billing 19/19 через штатный `bun run test`, doc-tools 10 успешных и 2 пропущенных. Сборка Vite успешна; остаётся предупреждение о крупных JS-частях. Это не проверка продового развёртывания.

## Ограничения

- Не обещается точное воспроизведение любой сложной Word-вёрстки после редактирования. Редакция нормализует документ; исходный файл всегда доступен отдельно.
- Подписи, макросы, интерактивные PDF-формы и графическое редактирование сканов не поддерживаются.
- Для старых загрузок, где раньше сохранялся только извлечённый текст, исходную разметку восстановить нельзя; нужно загрузить оригинал заново.
- В таблице предпросмотра отображаются первые 1000 строк и 100 колонок. Экспорт включает всю книгу. Это не полноценная замена Excel и не редактор диаграмм.
- Промышленная проверка сложных клиентских шаблонов и большого числа документов остаётся отдельным этапом. Изменения пока локальные, без развёртывания на проде.
