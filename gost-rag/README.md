# gost-rag — прототип ассистента по ГОСТам

Прототип для ML-трека: отвечать на вопросы по ГОСТам **со ссылками на конкретный пункт**,
**валидировать** ответ модели до выдачи пользователю, и **сравнивать** подходы (RAG vs RLM)
и модели (через OpenRouter) по качеству / цене / латентности.

> Тексты ГОСТов подключаются позже. Сейчас работаем на синтетических фикстурах
> (`data/fixtures/*.json`), повторяющих структуру стандарта (документ → пункты).
> Ингест устроен так, что подмена фикстур на реальный парсер PDF/сканов не трогает остальной пайплайн.

## Архитектура

```
ingest → chunk → index ─┐
                        ├─→ retrieve ─(rerank)─→ generate ─→ validate ─→ Result{answer, citations, validation, usage}
query ──────────────────┘
                          └─────────── eval harness: strategy × model × ablation → метрики
```

Всё за сменными интерфейсами; модель/стратегия/параметры меняются конфигом, не кодом.

| Модуль | Роль |
|---|---|
| `schema.py` | контракты (Document, Chunk, Citation, Answer, ValidationReport, Result) |
| `corpus.py` | ингест фикстур + **структурный чанкинг по пунктам** (основа точных ссылок) |
| `embeddings.py` | эмбеддинги через OpenAI-совместимый эндпоинт (self-host **Qwen3-Embedding-8B**) |
| `store.py` | Qdrant: dense-поиск + фильтр по отрасли |
| `generate.py` | генерация ответа + цитат (OpenRouter), строгий JSON |
| `validate.py` | **гард перед выдачей**: проверка цитат (пункт реально есть + дословная цитата) + LLM-судья faithfulness + abstain |
| `strategies.py` | `RAGStrategy` и `RLMStrategy` за одним интерфейсом |
| `agent.py` | `answer_gost_query(...)` — единая точка входа (**хук переиспользования** для матзаявок) |

### Две стратегии

- **RAG** — embed(запрос) → Qdrant dense-поиск → (опц. LLM-реранк) → генерация с цитатами.
- **RLM (Recursive Language Model)** — у контроллера НЕТ корпуса в контексте; он исследует
  его инструментами `grep`/`open` и может `recurse` — поручить под-вопрос свежему экземпляру
  модели на срезе пунктов (с ограничением глубины). Идея из *Recursive Language Models*
  (Zhang & Khattab, 2025): рассматривать корпус как среду для исследования и рекурсии, а не
  полагаться на recall векторного ретрива. *(Реализация — добросовестная интерпретация концепта;
  если хочешь, подтяну каноничный источник и выровняю детали REPL/рекурсии.)*

## Стек

Python + uv · **Qdrant** (вектор-стор, docker) · **OpenRouter** — один ключ на всё:
**Qwen3-Embedding-8B** (эмбеддинги), генерация, LLM-судья, RLM/мультиагент-подвызовы.
Самостоятельно поднимать эмбеддер не нужно.

## Запуск — в одну команду

```bash
cd gost-rag
cp env.sample .env            # впиши OPENROUTER_API_KEY (эмбеддинги берут тот же ключ)
make up                       # Qdrant + зависимости + индексация (dense + hybrid) — всё сразу
```

Дальше:

```bash
make ask q="Какие размеры полей у документа?"
make ask q="Как нумеруют страницы?" strategy=rlm
make eval                     # бенчмарк-матрица → eval/results.md
make eval model=anthropic/claude-3.7-sonnet   # ограничить одной моделью
make help                     # все команды (up/index/hybrid/ask/eval/test/dash/logs/down)
```

> Реальные ГОСТы: положи текстовые PDF в `data/gost_pdfs/`, пропиши `industry` в `data/registry.yaml`,
> затем `make up SRC=data/gost_pdfs`. Без Makefile всё то же доступно как `uv run python scripts/...`.

## Карта на задачи трека

1. **Вопросы по ГОСТу + ссылки** → весь пайплайн; цитата = `{gost_id, clause_path, quote}`, точность пункта держит структурный чанкинг.
2. **Корпус по отраслям** → поле `industry` в схеме + фильтр в Qdrant; парсеры подключаются в `corpus.py` (заглушка-фикстуры сейчас).
3. **Валидация ответов** → `validate.py` (детерминированная проверка цитат + LLM-судья + abstain) — запускается до выдачи.
4. **Системный промпт** → `prompts.py` (`SYSTEM_GOST`).
5. **Сравнение моделей лучше/дешевле** → `eval/run_eval.py` (качество × токены × латентность по `config/models.yaml`).
6. **Переиспользование (матзаявки)** → `answer_gost_query()` возвращает структурный `Result`; агент дёргается как под-задача/tool.

## Что реализовано vs дальше

- **Есть:** end-to-end RAG, RLM-контроллер с рекурсией, валидация (цитаты + судья), eval-матрица, CLI, фикстуры.
- **Дальше:** гибрид dense+BM25 (Qdrant sparse-векторы), нативный Qwen3-Reranker вместо LLM-реранка, реальные парсеры ГОСТов (PDF/сканы), расширение gold-набора, опц. трейсинг (Langfuse) и RAGAS-метрики (`uv sync --extra eval`).
