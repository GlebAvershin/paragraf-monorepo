# Handoff: Isaac — редизайн интерфейса (isaac-ai.ru)

## Overview
Isaac — ИИ-сервис для предприятий: сотрудники автоматизируют работу через общение с ИИ-моделями.
Этот пакет описывает **визуальный редизайн** существующего MVP. Палитра и концепция
светлая/тёмная тема сохранены из текущего продукта; цель редизайна — поднять визуальную
иерархию, «премиум»-ощущение и добавить движение (editorial-стиль «Restrained Editorial»
из фирменного `DESIGN.md`).

Пример-контент везде взят из реального сценария технолога (ГВС, ГОСТ, СанПиН).

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, собранные в HTML** (Design Components, `.dc.html`).
Это прототипы, показывающие задуманный вид и поведение, **а не готовый production-код для
копирования**. Задача — **воссоздать эти экраны в текущей кодовой базе Isaac**
(десктоп-приложение — форк opencode на SolidJS + лендинг на Astro) её же паттернами и
библиотеками. HTML использовать как точную спецификацию (токены, размеры, копирайт,
поведение), а не переносить дословно.

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы, скругления, тени и
взаимодействия. Воссоздавать UI пиксель-в-пиксель средствами текущего стека Isaac.

### Шкалы
- **Скругления:** поля/чипы `6–8px`; кнопки/малые карточки `9–11px`; крупные карточки/панели `13–16px`; капсулы/пилюли/аватар `9999px`.
- **Отступы карточек:** мелкие `18–22px`, крупные `24–32px`.
- **Сетки:** контентные страницы центрируются `max-width` (Чат-колонка `720px`, Настройки `900px`, Кредиты/Аналитика `960–1000px`, Помощь `760px`, Главная/История `880–1080px`) с внешними полями `40px`.
- **Зернистость:** фиксированный оверлей `radial-gradient(var(--grain) 1px, transparent 1px); background-size:4px 4px; pointer-events:none`.

### Логотип
Слово **Isaac** набрано `--serif`, `font-weight:500`, `letter-spacing:-0.01em`.
Буква **I** — цвет `var(--accent)` (изумруд), **saac** — `var(--text-primary)` (чёрный).
Реализуется двумя вложенными `<span>`. Размеры: топ-бар `18px`, сайдбар `20px`.

## Screens / Views

Приложение — одностраничное с переключением экранов по состоянию `screen`.
Верхний бар навигации (sticky) содержит: логотип, метку, пилюли-навигацию
(**Главная · Кредиты · История · Аналитика · Настройки · Помощь**) и тумблер темы.
Активная пилюля — фон `--accent`, текст `--on-accent`.

> Примечание: «Чат-сессия» — **не** пункт навигации. Это рабочий экран, открывается
> по клику на сценарий или «Новая задача»; возврат везде ведёт на Главную.

### 1. Главная (`home`) — начальная страница при входе
- **Назначение:** старт работы. Первое, что видит сотрудник.
- **Layout:** центрированная колонка `max-width:1080px`, паддинг `56px 40px 80px`.
  - Шапка: слева заголовок-серифа «С чего **начать?**» (52px, «начать» — italic + accent) и
    подзаголовок; справа сегмент-переключатель профессии (Технолог/Юрист/Бухгалтер, капсула).
  - Сетка сценариев `grid-template-columns:1.6fr 1fr; gap:16px`: крупная промо-карточка
    (фон `--accent`, текст `--on-accent`, `grid-row:span 2`) «Разобрать требование ГОСТа» +
    две карточки справа. Ниже — ряд из трёх карточек (`repeat(3,1fr)`).
  - Блок «Продолжить работу»: заголовок-серифа + ссылка «Вся история →» (accent);
    карточка `--surface` со списком последних сессий (название, бейдж «N находок», время).
- **Поведение:** любая карточка сценария и строка сессии → открыть Чат (`screen='chat'`).
  «Вся история →» → История.

### 2. Чат-сессия (`chat`) — трёхпанельный рабочий экран
- **Назначение:** диалог с ИИ + разбор документа рядом.
- **Layout:** `display:flex; height:calc(100vh - 53px)`. Три панели:
  - **Сайдбар `264px`** (`--surface-alt`): логотип+метка; кнопка «+ Новая задача»
    (акцентная, во всю ширину, → Главная); блок «Сценарий» (активный чип); список «История»
    (активный пункт — `--surface` + рамка, остальные — ховер `--inset`); внизу — карточка
    кредитов (прогресс-бар 69%, «1 173 / 1 700», сброс через 4 дня, → Кредиты) и мини-ссылки
    Настройки / Аналитика / Помощь.
  - **Центр (чат)**: хедер сессии (мета-строка mono + заголовок-серифа 19px + чип модели
    «Claude Sonnet 4.6 ×1.5»); прокручиваемая лента `max-width:720px`:
    - Сообщение пользователя: карточка `--surface`, рамка `--hairline-strong`, вложение-файл
      (mono-бейдж «PDF» на `--error`, имя, «2 стр.»).
    - Ответ Isaac: строка-автор (кружок-инициал «I» серифа-italic + mono-метка «Isaac · разбор»
      + кнопка «⟳ Сгенерировать заново» справа). Далее **нумерованный разбор** (01/02/03):
      каждая находка — mono-номер, заголовок, статус-бейдж (Несоответствие=`--warning`,
      Соответствует=`--accent`, Замечание=`--highlight`), пояснение. Затем блок «Итог»
      (левый бордер `--accent`, фон `--accent-muted`) и финальная строка «печатается».
    - Футер: поле ввода (карточка с тенью) — «+», чипы «Углублённо» / модель, «~8 кредитов»,
      круглая кнопка отправки «↑».
  - **Правая панель `392px`** (`--surface`): «Документ · выдержка» — заголовок норматива,
    кнопки экспорта DOCX/MD/PDF, текст выдержки с **подсвеченным спорным пунктом**
    (п.84, левый бордер `--accent`, фон `--accent-muted`, mono-маркер «01»).
- **Поведение:** «⟳ Сгенерировать заново» перезапускает streaming-анимацию (см. ниже).

### 3. Кредиты и подписка (`credits`)
- **Назначение:** баланс, множители моделей, подписка, история платежей, докупка.
- **Layout:** `max-width:1000px`. «← Назад» → Главная. Заголовок-серифа.
  - Сетка `1.5fr 1fr`: слева карточка баланса — крупное число серифой «1 173 / 1 700»,
    прогресс-бар 69%, блок «Цена модели» (три строки множителей 1.0× / 1.5× / 2.2× с
    цветными маркерами `--text-tertiary` / `--accent` / `--highlight`), кнопки «Докупить +500»
    (акцент) и «Сменить тариф». Справа — карточка «Подписка» (тариф, стоимость, дата списания,
    карта, докуплено) + плашка-подсказка на `--highlight-muted`.
  - Ниже — «История платежей»: mono-шапка таблицы + строки (`grid-template-columns:120px 1fr 120px 100px`).

### 4. Аналитика (`analytics`)
- **Назначение:** расход кредитов по дням/моделям/сценариям + выгрузка CSV.
- **Layout:** `max-width:960px`. «← Назад» → Главная. Сегмент Неделя/Месяц/Год.
  - Три метрики (`repeat(3,1fr)`): «Всего кредитов 1 366», «Запросов 26», «Средне 52.5» —
    числа серифой 40px.
  - Карточка «Расход по дням»: **столбчатый график** из 14 `<div>` (высоты в `%`, чередование
    `--accent` / `--accent-muted`), анимация роста `barGrow` со сдвигом задержки по столбцам.
  - Две карточки: «По моделям» (стек-бар 62/28/10% + легенда) и «По сценариям» (список сумм).

### 5. Настройки / профиль (`settings`)
- **Назначение:** профиль, оформление, модель по умолчанию.
- **Layout:** `max-width:900px`. «← Назад» → Главная.
  - Карточка профиля: круглый аватар-инициалы на `--accent`, имя/почта/роль, бейдж тарифа.
  - «Оформление»: сегмент Светлая/Тёмная (управляет темой), тумблер «Чисто-белый фон»
    (отключает кремовый оттенок — хедж из DESIGN.md), тумблер «Крупный шрифт».
  - «Модель по умолчанию»: три радио-строки (Lite 1.0× / Sonnet 1.5× выбрана / Opus 2.2×).

### 6. Помощь (`help`)
- **Назначение:** FAQ-аккордеон + контакт поддержки.
- **Layout:** `max-width:760px`. «← Назад» → Главная. 7 раскрывающихся вопросов
  (компонент `IsaacFaqItem`, первый открыт по умолчанию).

### 7. История задач (`history`)
- **Назначение:** полный список сессий с поиском и экспортом.
- **Layout:** `max-width:880px`. «← Назад» → Главная. Кнопка «+ Новая задача» (→ Чат).
  - Строка поиска (плейсхолдер + бейдж «⌘K»).
  - Группы «Сегодня» / «Вчера» (mono-заголовки). Раскрытая карточка сегодняшней задачи:
    заголовок, время+кредиты, краткое описание, бейджи «3 находки»/модель, кнопки DOCX/MD/PDF.
    Остальные — компактные строки (название + время+кредиты).

## Interactions & Behavior
- **Навигация:** переключение `screen` без перезагрузки; активная пилюля подсвечена.
  «← Назад» и «Новая задача» из сайдбара ведут на Главную; карточки сценариев/сессий → Чат.
- **Переключение темы:** тумблер в топ-баре и сегмент в Настройках меняют `theme`
  (`light`↔`dark`) → атрибут `data-theme`. Переход `transition: background .3s, color .3s`.
- **Streaming-анимация ответа (Чат):** при показе ответа блоки появляются каскадом —
  интро → находка 01 (`fadeUp`, delay .25s) → 02 (.5s) → 03 (.75s) → «Итог» (1s) →
  финальная строка по словам (`word`, шаг ~.08s) с мигающей кареткой (`caret`, шаг 1s).
  Кнопка «⟳ Сгенерировать заново» сбрасывает и проигрывает заново (`showGen` → false, затем
  через 150мс → true).
- **Ховеры:** пилюли/строки истории — фон `--inset`; карточки — рамка `--hairline-strong` +
  фон `--surface-alt`; акцентные кнопки — `--accent-hover`; строки «Продолжить работу» —
  сдвиг `padding-left:8px`.
- **FAQ:** клик по вопросу раскрывает/сворачивает; иконка «+» поворачивается на 45° (`.2s`).

### Keyframes
```css
@keyframes fadeUp { from { opacity:0; transform:translateY(6px);} to { opacity:1; transform:none;} }
@keyframes caret  { 0%,45%{opacity:1;} 55%,100%{opacity:0;} }
@keyframes word   { from {opacity:0;} to {opacity:1;} }
@keyframes barGrow{ from {transform:scaleY(0);} to {transform:scaleY(1);} } /* transform-origin:bottom */
```

## State Management
- `screen`: `'home' | 'chat' | 'credits' | 'analytics' | 'settings' | 'help' | 'history'` (старт — `home`).
- `theme`: `'light' | 'dark'` (старт — `light`). В продукте — персистить (localStorage / профиль).
- `showGen` (Чат): boolean, управляет проигрыванием streaming-анимации.
- В `IsaacFaqItem` — локальный `open` на каждый вопрос.
- Демо-данные (баланс, история, метрики) в продукте берутся из API.

## Components (переиспользуемые)
- **IsaacScenarioCard** — карточка сценария на Главной. Props: `num`, `tag`, `title`, `desc`,
  `steps`, `onSelect`. Ховер: рамка `--accent` + фон `--surface-alt`.
- **IsaacFaqItem** — раскрывающийся вопрос в Помощи. Props: `q`, `a`, `open`. Своё состояние.

Повторяющиеся паттерны, которые в реальном коде стоит вынести в компоненты:
строка-находки (номер+заголовок+статус-бейдж), строка истории/сессии, метрика-число,
статус-бейдж (варианты warning/accent/highlight), капсула-множитель модели.

## Assets
Иконографика — текстовые глифы (`+`, `↑`, `→`, `✕`, `⟳`, `⌕`, `←`), без внешних SVG.
В продукте заменить на иконочный набор кодовой базы. Логотип — типографика (без картинки).
Аватар — инициалы на изумрудном круге. Реальные файлы пользователя (PDF/DOCX) — из бэкенда.

## Files
- `Isaac Redesign.dc.html` — все 7 экранов + токены + темы + анимации (главный референс).
- `IsaacScenarioCard.dc.html` — компонент карточки сценария.
- `IsaacFaqItem.dc.html` — компонент FAQ-строки.
- `DESIGN.md` (копия из TEMKA) — фирменная дизайн-система «Restrained Editorial» (источник правды).

Открывать `.dc.html` можно прямо в браузере. Токены и точные значения — брать из `:root`
в `Isaac Redesign.dc.html` и из таблиц выше.
